    PROVENANCE & PRIVACY

    Training data, evaluation and privacy

    Training data

    The classifier is trained on 2,000 synthetic rows generated by src/generate_data.py (200 per class, with 1% synthetic label noise). These are generated examples, not measured vehicle records.

    Model and evaluation

    A scikit-learn Decision Tree is selected with five-fold macro-F1 cross-validation on the training split, then evaluated on a separate stratified 400-row test split. Reported test metrics describe this synthetic dataset only; performance on real vehicles has not been established.

    How information is handled

    Specifications are sent to this app's server for inference. Up to 20 recent predictions are stored in this browser's local storage. CSV data is processed for the request; video uploads use a temporary server file that the app attempts to delete after analysis. Hosting logs and retention depend on the deployment provider. The page also requests fonts from Google Fonts. Avoid submitting sensitive information.

    Class schemes

    How many classes?

    There's no single universal list of classes. A simple project uses 4 to 6 classes (bike, car, bus, truck). The US Federal Highway Administration uses a 13-class scheme based largely on axle count and configuration. Indian systems often add classes for auto-rickshaws, e-rickshaws, tractors and light commercial vehicles, so define your classes before collecting data.
